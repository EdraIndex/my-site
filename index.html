The engagement, in order

Six steps. None of them fills a gap for you.

  1. 01

    Send what you have.

    One .xlsx workbook, holding the figures you already have, in the shape you already hold them.

    A blank cell stays blank.
  2. 02

    EDRA returns the position from what was sent.

    For each requirement: what the workbook supports, and what it does not.

    Not an assurance. Not a rating.
  3. 03

    What is missing is an ask, not a guess.

    Each gap goes back to you as a specific request. You send the figure with the file it came from.

    The file is held and hashed, not read.
  4. 04

    An analyst accepts or rejects.

    A person decides on every reply. Nothing is accepted automatically.

    An estimate is refused. A reply with no file waits.
  5. 05

    The rerun is a new calculation.

    Accepted figures go into a fresh run. It does not overwrite the one before it.

    The first is preserved.
  6. 06

    The board line is the latest calculation.

    Each line says one of three things, and only what the latest run supports.

    Answered, partial, or not sayable.
